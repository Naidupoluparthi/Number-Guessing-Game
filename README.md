# 🎮 Number Guessing Game

## 📌 Project Overview

The Number Guessing Game is a simple Java console-based application in which the computer generates a random number between 1 and 100, and the user tries to guess it within five attempts.

The program provides feedback after each valid guess, helping the user determine whether their guess is too high or too low.

## ✨ Features

- Generates a random number between 1 and 100.
- Allows up to five valid guessing attempts per game.
- Displays hints such as "Too High!" and "Too Low!".
- Notifies the user when they guess the correct number.
- Displays the number of attempts taken to win.
- Reveals the secret number if the user runs out of attempts.
- Allows the user to play again without restarting the program.

## 🚀 How to Run the Project

1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Open the project in Eclipse or another Java IDE.
4. Locate `NumberGuessingGame.java` inside the source folder.
5. Run the `NumberGuessingGame` class.
6. Follow the instructions displayed in the console.

## 🎯 How to Play

1. The program generates a secret number between 1 and 100.
2. Enter your guess when prompted.
3. Read the hint displayed by the program.
4. Continue guessing until you find the correct number or use all five attempts.
5. Choose whether to play another round.
